# LaafStyl Shuttle

West Coast shuttle service booking page. Instant fare calculator, WhatsApp booking.

- **Live:** https://shuttle.laafstyl.org
- **Tech:** Single-page HTML + CSS + JS, no framework. `assets/hero.js` handles the hero route-map animation, lazy video and mobile-nav accessibility only; the fare calculator and WhatsApp booking code are inline in `index.html`.
- **Booking:** WhatsApp-based (opens wa.me with a pre-filled message).
- **Operator:** BROD Traders (Pty) Ltd, Langebaan, Western Cape.
- `_archive/` holds the original uncompressed hero clip (not served).
